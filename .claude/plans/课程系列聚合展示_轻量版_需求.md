# 课程系列聚合展示需求（轻量版）

> 状态：待确认
> 
> 目标：在尽量少改动现有代码的前提下，解决系列课程占满课程列表、影响其他课程浏览的问题。

## 1. 背景

当前课程列表以单门课程为单位展示。一个系列通常包含十多节课，每节课都单独占用一个课程卡片，导致列表过长、其他课程不易浏览。

系统已有课程标签筛选能力。本需求复用该能力：为系列课程增加统一的系列标签，默认列表将同系列课程聚合为一个系列卡片；用户点击后进入现有标签筛选结果，查看系列内全部课程。

## 2. 本期目标

1. 同一系列课程默认只占用一个列表卡片。
2. 系列卡片采用多卡片重叠视觉效果，表达“课程集合”。
3. 点击系列卡片后，复用现有标签筛选逻辑展示该系列全部课程。
4. 保留每门课程原有详情、预览、购买和权限逻辑。
5. 没有系列标识的课程展示方式保持不变。
6. 保留现有学科、关键词、普通标签和分页能力。

## 3. 本期不做

- 不新增系列表或套餐表。
- 不新增系列订单或批量授权。
- 不实现一键购买整套课程。
- 不实现套餐价格、优惠、差价、退款或有效期。
- 不修改 `course_order`、积分支付和单课权限逻辑。
- 不实现系列独立详情页、独立封面管理或系列级学习进度。
- 第一版一门课程最多属于一个系列。

## 4. 系列标识

复用现有 `course.tags` 字段，但系列标签必须使用固定前缀，建议格式：

```text
系列课程:Python入门
```

要求：

- 同一系列的课程使用完全相同的系列标识。
- 系列名称不能为空。
- 系列标签与普通标签区分处理，不在普通标签列表中展示。
- 程序识别时必须按完整标签精确匹配，不能直接使用裸 `LIKE '%名称%'`，避免 `系列课程:Python` 与 `系列课程:Python进阶` 误匹配。
- 后台优先提供系列选项或统一生成标签，不要求管理员手工拼写特殊标签。
- 课程新增/编辑页增加“所属系列”选项；无系列时为空。
- 本轻量版不新增“系列内排序”字段，直接复用现有 `course.sort_order` 作为系列内排序，`id` 作为同序号时的兜底。
- 后台继续编辑现有课程排序值；需要调整系列内顺序时调整对应课程的 `sort_order`。因此该排序同时会影响未进入系列筛选时的全局课程排序。
- 如果后续要求“系列内排序”和全局课程排序完全独立，再新增 `series_sort` 字段，并另行补充 SQL 归档与发布流程。

## 5. 默认列表行为

当用户未进入某个系列筛选页时：

- 每个系列只保留一个系列代表卡片。
- 无系列课程继续显示普通课程卡片。
- 系列卡片与普通课程卡片混合展示。
- 系列卡片不显示代表课程的单课价格、单课购买按钮或单课购买状态。
- 系列卡片显示系列名称、课程数量、总课时和“查看系列课程”按钮。
- 系列封面第一版使用系列内排序第一的课程封面。

示例：

```text
Python入门系列课程
共 12 门课程 · 共 18 课时
[查看系列课程]
```

如实现成本可控，可显示“已拥有 X/12 门”；否则第一版不显示系列级购买概况，避免扩展订单查询。

## 6. 系列卡片视觉

系列卡片使用主卡片加 2～3 层错位背景卡片的 CSS 装饰：

- 背景卡片仅用于视觉，不单独可点击。
- 主卡片标题、课程数量和按钮必须完整可读。
- 鼠标悬停可轻微抬升或展开。
- 整个主卡片可点击，按钮与卡片行为一致。
- 键盘焦点清晰。
- 移动端降低旋转和重叠幅度，禁止横向滚动。
- 不实际渲染系列中的全部课程卡片作为装饰。

## 7. 点击行为

点击系列卡片或“查看系列课程”后，跳转到现有课程列表页并带系列标签筛选参数，例如：

```text
course.php?tag=系列课程%3APython入门
```

进入系列列表后：

- 取消默认系列去重。
- 显示该系列内全部匹配课程。
- 恢复现有单课卡片样式。
- 保留单课价格、购买状态和详情链接。
- 每门课程继续进入 `course_info.php?id=...`。
- 可在页面顶部显示“当前系列：Python入门”和“返回全部课程”。

按钮统一使用“查看系列课程”，本期不使用“购买整套”等会暗示套餐交易的文案。

## 8. 筛选与分页

### 默认列表分页

默认分页单位为“系列卡片 + 无系列课程卡片”。不能先按全部课程分页，再在模板中隐藏同系列课程，否则同一系列会跨页、分页数量错误或出现空白页。

### 系列列表分页

进入系列标签筛选后，恢复原有课程级分页，展示该系列课程。

### 其他筛选条件

第一版建议采用以下简化规则：

- 无搜索关键词、无普通标签筛选时，启用系列聚合。
- 使用关键词或普通标签筛选时，保持原有课程级列表，避免复杂筛选组合造成分页语义不清。
- 学科筛选可继续保留；若实现成本可控，按筛选结果聚合并显示匹配数量。
- 所有分页链接保留当前筛选参数。

## 9. 购买与权限兼容

本期完全复用现有单课流程：

- 单课详情不变。
- 预览版购买不变。
- 原文件版购买不变。
- 原文件版补差价升级不变。
- 单课订单和积分支付不变。
- 单课权限判断不变。
- 系列聚合不得绕过课程详情页权限校验或泄露资源链接。

## 10. 预计涉及文件

后端：

```text
trunk/web/course.php
trunk/web/admin/course_add.php
trunk/web/admin/course_edit.php
```

前端：

```text
trunk/web/template/syzoj/course.php
```

如当前文案使用语言包，再同步增加系列相关文案。其他模板目录不修改。

## 11. 数据库与发布

本轻量方案只复用现有 `course.tags`，不新增表、不执行 `ALTER TABLE`，因此：

- 不新增 `db/` SQL 归档；
- 不更新 `db/RELEASE_STEPS.md`；
- 不需要数据迁移。

若后续增加独立系列表、系列封面、套餐价格或系列订单，则应重新设计并按项目规范新增 SQL 归档。

## 12. 验收标准

### 展示

- [ ] 同系列课程默认只显示一个系列卡片。
- [ ] 无系列课程展示方式不变。
- [ ] 系列卡片显示系列名称、课程数和总课时。
- [ ] 系列卡片具有多卡片重叠视觉效果。
- [ ] 移动端无横向滚动。

### 点击

- [ ] 点击系列卡片进入系列标签筛选列表。
- [ ] 系列列表显示系列内课程。
- [ ] 系列列表恢复原有课程卡片。
- [ ] 每门课程可进入原详情页。
- [ ] 可返回全部课程列表。

### 筛选与分页

- [ ] 默认分页按系列卡片和独立课程计算。
- [ ] 同一系列不会被拆到默认列表的多个页面。
- [ ] 系列列表可正常分页。
- [ ] 学科、关键词和普通标签筛选不回归。
- [ ] 分页链接保留筛选条件。
- [ ] 系列技术标签不显示为普通标签。

### 购买兼容

- [ ] 单课详情、预览购买、原文件购买和升级无回归。
- [ ] 现有订单无回归。
- [ ] 不产生系列订单或批量授权记录。
