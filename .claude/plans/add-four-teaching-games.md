# more.php 新增 4 款教学小游戏（七巧板/火柴棒算式/坐标寻宝/天平方程）

## 目标

more.php 小游戏区补充"交互有趣、画面可爱"的场景化教学游戏，对标现有标杆：拼图游戏（拖拽交互）与青蛙过河（全屏场景+关卡+星星）。新增 4 款纯前端游戏，移动端一屏自适应，面向小学 1-6 年级。

**根因**：现有低年级游戏多为"出题→点答案"静态模式，缺乏强交互、场景化的教学游戏。

## 方案取舍

- **同构现有架构**：每游戏 = `template/syzoj/` 单文件 HTML（内联 CSS/JS，无构建）+ `trunk/web/` 薄 PHP 包装（复制 `frog_typing.php` 结构），与现有 17 款完全一致
- **全屏场景风**：沿用 frog_typing.html 已验证的 `.padding` 覆盖方案（去白玻璃底），一游戏一世界观，素材来自教具原型
- **无 DB、无积分、无后端**：进度存 localStorage；无 SQL 归档
- **共享骨架、各自皮肤**：一屏自适应（flex-start 靠上 + clamp + JS 动态算格子 + safe-area）、`prefers-reduced-motion`、canvas-confetti CDN + `game_confetti.js`、站酷快乐体标题（自托管 fonts/zcool-kuaile.css）

## 游戏规格

### 🪵 七巧板 · 木片小工坊（低年级，免登录）

- **世界观/配色**：暖木桌面（米纸底 `#FAF3E3` + 淡方格纹），7 板 7 糖果色（柿红/杏黄/芽绿/湖蓝/藤紫/蜜桃粉/暖木棕），深咖 ink `#4A3728`
- **玩法**：标准 7 块七巧板拖入剪影区；**点一下选中→有"旋转 45°"按钮**（不用双击/长按），拖到目标姿态 ±10°/±8px 内磁吸；7 块全部落位 = 通关
- **关卡**（8 关渐难）：前 3 关（猫/房子/鱼）给彩色半透明填充提示；后 5 关（船/兔子/火箭/骆驼/天鹅）只给灰色剪影
- **标志性动效**：通关时剪影"活过来"（整体 wiggle + 某块板脉动发光）+ 礼花弹窗
- **教学点**：图形组合、旋转、面积守恒；卡片文案"适合1-3年级"

### 🔥 火柴棒算式 · 小火苗的夜课（高年级，需登录）

- **世界观/配色**：靛蓝夜色 `#1E2A52→#121A38` 渐变 + 萤火虫光点（4 款中唯一暗色主题）；暖木火柴杆 `#D9A05B` + 朱红火柴头 `#E34A33`，点燃琥珀光晕 `#FFB347`
- **玩法**：等式（如 `3+2=5`）用七段码式火柴段渲染数字。谜题 = 移动 1 根火柴使等式成立；**点火柴拿起（抬起+投影）→ 点目标格放下**，非法放置弹回抖动
- **关卡**：内置 12 题分 3 档（入门数字增删、进阶数字变形如 6→9、困难改变运算符）
- **标志性动效**：等式成立瞬间整排火柴头从左到右依次点燃 + 金色粒子向上飘 + 礼花
- **教学点**：等式概念、逆向思维；卡片文案"适合3-6年级"

### 🗺️ 坐标寻宝 · 小海豚航海图（高年级，需登录）

- **世界观/配色**：牛皮纸海图 `#F0E2C4` + 湖蓝经纬线 `#5B8FB5` + 珊瑚红航线 `#E37B60` + 金色宝箱；小海豚主角青蓝
- **玩法**：网格海图宝箱在随机格；**点格子或输入 (x,y)** 双方式，主角逐格跳跃（squash & stretch）沿虚线到达；错误给方向提示（"再往东 2 格"）
- **关卡**：第一象限正整数 → 距离/方向提示辅助 → 四象限含负数 → 限时挑战
- **标志性动效**：到达时宝箱爆开金币四溅 + 礼花
- **教学点**：直角坐标系（编程前置知识）；卡片文案"适合4-6年级"

### ⚖️ 天平方程 · 水果摊的秘密（高年级，需登录）

- **世界观/配色**：红白条纹遮阳篷页头 + 摊位木色 `#B5835A`；苹果红/橘子橙/柠檬黄糖色砝码，神秘盒紫 = 未知数 x
- **玩法**：木质天平左盘放神秘盒+已知水果，右盘拖水果配平；天平**实时倾斜**（transform 按重量差插值）；教学"两边同时拿走"消元思想
- **关卡**：感知天平（比大小）→ 估算神秘盒（x=?）→ 两边同加减消元（3 关一组）
- **标志性动效**：天平实时物理感倾斜 + 配平瞬间"叮"波纹扩散 + 水果表情
- **教学点**：等式两边同变、代数启蒙；卡片文案"适合4-6年级"

## 设计自查（避免生成感）

- 默认做法会是"四张同款渐变标题白卡片"——已否定，改为一游戏一场景，素材全部来自教具原型（木片/火柴/海图/遮阳篷）
- 火柴棒用暗色主题是有意的冒险：火焰发光需要夜色，且打破全站浅色单调
- 不用 ALL-CAPS 眉标、不用"·"串接 meta 行；装饰只保留每游戏一个标志性瞬间，其余收敛为微反馈
- 技术上沿用青蛙过河已验证的 `.padding` 覆盖方案做全屏场景
