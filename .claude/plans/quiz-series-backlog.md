# 趣味测评系列选题需求池（Backlog PRD）

> 用途：后续趣味测评 H5 的选题库 + 通用实现规范。每个选题开工前，从本文件摘取对应章节生成单题实施计划（仿 `.claude/plans/career-test.md` / `teacher-style-test.md`），经确认后按工作流实现：**coder 编码 → reviewer 验收，不派 tester**（测评系列工作流：编码后 review 即可，浏览器观感由用户实测反馈，2026-09-27 调整）。
> 沉淀日期：2026-09-27。调研方法：小红书/淘宝/微信生态情绪测试与 1 元情绪商品钩子归纳（网易云「人格主导色」、MBTI 系刷屏 H5、新世相式事件 H5、"爱因斯坦的智力给我"类 1 元商品）。

## 一、产品策略（系列总纲）

- **定位**：钩子型内容，用好奇心/情绪价值吸引老师与家长点进来测、转发，为课程表 / 课件 / 课前小游戏 / 登录导流。
- **双测组合已上线**：
  1. 《测一测你是哪位教育家》（teacher_style_test）——理想自我 / 伟人对标 / 绘本可爱风
  2. 《测一测，你该不该考编？》（career_test）——现实困境 / 决策解忧 / 解忧杂货铺便签风
- **系列调性**：毒舌暖心、自嘲不刻薄；结果必须"替用户说出心里话"（1 元情绪商品卖的是"被允许"）；焦虑类选题必须给出气口（轻松出口 + "仅供娱乐参考"）。
- **节奏建议**：第三测优先补**家长向**（拉新家长用户群，与教师向形成人群互补）；第四测起可按开学/期末节点投放运营款。

## 二、爆款规律（选题与文案约束）

1. **决策钩子 > 身份钩子**："我要不要 X"比"你是哪种 X"点击天花板更高——用户在把决策外包给测试。
2. **标题公式**：`测一测 / 8 道题 + 低门槛数字 + 结果悬念或二选一困境`；副标题用民间语感的情绪共鸣句（"不写作业母慈子孝"式），不低俗、不恐吓。
3. **结果人格命名**：阵营感 + 自嘲感（"编制真香党""气氛组"），画像"像我、但比我有趣"；匹配度锁 **70%~97%** 给台阶；每条结果自带一句金句。
4. **晒点前置**：结果页天生是海报卡（称号 + 金句 + 二维码）；分享文案第一人称可直接粘贴；配"隐藏第二人格/重测"钩子提复玩。
5. **焦虑要给出气口**：测焦虑、卖"被理解"；结果页必须轻松出口 + 免责，防止教育平台形象反噬。

## 三、通用实现规范（每题开工时强制复用）

| 项 | 规范 |
|----|------|
| 架构 | 纯前端本地计算；无需登录；不落库、无个人信息、无埋点、无 DDL（游客白名单开放，传播优先） |
| 文件 | 控制器 `{name}_test.php`（照 teacher_style_test.php 模式）+ `template/syzoj/{name}_test.php`（四态单页：落地/答题/结果/分享卡）+ `template/syzoj/js/{name}_test_data.js`（题库画像分离可热更）+ more.php 入口卡 + header.php `$guest_whitelist` 条目 |
| 模板 | **只动 `template/syzoj/`**（guard_template hook 机械拦截其他模板） |
| 页面外壳 | **极简壳**：模板置 `$hide_chrome = true` 后再 include header.php——隐藏 OJ 顶栏菜单与页脚主体（联系弹窗/客服 QQ/小红书推广一并不输出，semantic/Chart/js.php 站点脚本跳过，省移动端流量），保留 head 骨架 + 限流反爬 + 一行极简署名（© $OJ_NAME · 备案 · 返回首页）。默认关闭不影响其他页面；已上线两测已改造（2026-09-27）。**注意 body 高度必须 100%，见"已修坑"** |
| 题库 | 8 题 × 4 选项，隐藏权重；每维度至少 2 个选项触达（权重≥2）、方向全局一致无负分；权重只存数据文件 |
| 算法 | 答案 → 维度偏好向量 → 画像向量相似度 → 映射 **70%~97%**（恒钳制）；Top1 主结果 + Top2 隐藏第二人格 |
| 结果页 | 立场/称号揭晓（视觉锤）→ 匹配度环 → 标签胶囊 → 金句 → 个性化理由 80~150 字（高分维度 2 变体轮换拼接）→ 雷达 → 第二人格 → 转化区（3 导流 + 登录轻提示）→ 分享/重测 → "仅供娱乐参考" |
| 分享卡 | Canvas 750×1334 竖版：称号 + 匹配度 + 标签 + 金句 + 钩子文案 + $OJ_NAME + 二维码（本地 `js/qrcode.min.js`）；微信"长按保存"引导 |
| 导流 | 课程表生成器 timetable.php / 课件 course.php / 课前小游戏 more.php#games + loginpage.php 轻提示，口号式衔接不硬广 |
| UI | 先读 `.claude/skills/frontend-design/SKILL.md` 两遍工作法；移动端 375px 优先、触控 ≥44px、`prefers-reduced-motion` 降级、类名前缀防冲突；**每题独立视觉锤**，避免系列同质化 |
| 二维码 | 底层 vendor 复用 `template/syzoj/js/qrcode.min.js`（三页共用）；`makeQrCanvas()` 封装目前是三份拷贝（见下方"技术债"），**新测评不要再抄第四份**，等共享封装落地后引入 |
| 已修坑 | 雷达顶标签 dy 须 +12（负值会被 viewBox 裁切，teacher_style_test/career_test 均已修，勿回退）；分享卡金句最多 2 行防撞署名；环动画须 cancelAnimationFrame；match 匹配钳制用固定锚点映射即可；**极简壳 body 高度必须 100%（禁 auto）**：header.php 的 html 是 `position:fixed; overflow:hidden`，全站滚动靠 body 固定高度 + `overflow-y:overlay` 当滚动容器，height:auto 会超出一屏被裁死且无法滑动（2026-09-27 踩坑实测） |
| 验证 | `php -l` + `node --check` + 权重校验脚本 → deploy_test_env.sh `-f` → **reviewer 验收即可，不派 tester**（浏览器观感用户实测）；脚本断言类（登录态 POST/DB 核对）主会话按 deploy-test-env skill 配方直接跑 |

### 技术债：二维码/Canvas 工具重复拷贝（第四测开工前重构）

**现状**（2026-09-27 排查）：`makeQrCanvas()` 封装三份拷贝，结构一致（try/catch + `typeof QRCode` 静默降级 + holder div 取 canvas），仅 `colorDark` 按各自主题色不同：

| 位置 | colorDark |
|------|-----------|
| `js/timetable.js:362` | `#2f2413`（墨棕，配课表底图） |
| `teacher_style_test.php:772` | `#2B4C6F`（墨青，绘本风） |
| `career_test.php:813` | `#28282A`（墨字，便签风） |

**重构方案**（第四测/第五测前完成，防止拷贝涨到五份）：

1. 抽共享封装 `template/syzoj/js/qr_helper.js`：导出 `makeQrCanvas(text, size, colorDark)`，三处改为引入并传各自主题色（默认值 `#28282A`）
2. 顺带把各页重复的 Canvas 小工具（如 `wrapLines` 换行、`roundRect` 圆角）一并收编进同一 helper（或独立 `canvas_helper.js`），签名统一
3. 验收：三页分享卡各验一次二维码正常生成（course/teacher/career 三测分享卡截图对比，颜色与主题一致）+ `node --check`；无行为变更

**排期**：作为**第四测开工的前置任务**单独小改（单文件抽取 + 三处替换，半天内）；也可在第四测 coder 派单时合并做（plan 里写明先重构后写新题）。

## 四、选题清单（按优先级）

### P0-1 《8 道题，鉴定你的陪读精神状态》【第三测首选：家长向】

- **标题变体**：《辅导作业时的你是哪种"物种"？》/《8 道题，鉴定你的陪读精神状态》/《不写作业母慈子孝，一写作业鸡飞狗跳？》
- **钩子**：每晚 19:00–21:00，你家客厅上演的是温情片还是动作片？8 道题，鉴定你的陪读人格。
- **人群与动机**：小学生家长（妈妈为主）。辅导作业全民痛点 + 自嘲宣泄 + **家长群强转发场景**（本系列家长向传播场景最强的一款）。
- **8 题场景**：①孩子把 b 写成 d 第 N 次 ②孩子说"老师不是这么教的" ③应用题读 5 遍仍空着 ④边写边抠橡皮 ⑤书包里翻出忘交的作业 ⑥考 95 分却藏试卷 ⑦家长群有人晒奖状 ⑧写完扑过来要抱抱
- **结果人格（5）**：**咆哮帝后·悔恨型**（吼完就内疚，内疚完继续吼）/ **佛系放养派**（作业是孩子的修行，你的任务是活着陪到毕业）/ **军师型鸡娃**（错题本和艾宾浩斯都备好了，缺个不掉链子的娃）/ **彩虹屁大师**（别人靠血压，你靠演技）/ **隐形心大型**（人在这魂在刷手机，老师一@全体成员你秒醒）
- **分享文案**："鉴定完毕：我是咆哮帝后，今晚开始立地成佛。"
- **导流**："让娃先去课前小游戏放电 10 分钟"→ more.php#games；"用课件让娃自己学一会儿"→ course.php；登录绑定班级看学习动态
- **视觉建议**：客厅夜战情景喜剧风（暖黄台灯 + 漫画分格），与前两测均区分
- **维度设计提示**：情绪爆发度 / 佛系度 / 计划性 / 演技(正向激励) / 陪伴投入度

### P0-2 《测一测，你该不该跳槽？》【决策钩子正统续作，泛职场】

- **标题变体**：《测一测，你该不该跳槽？》/《你的跳槽时机成熟了吗？》/《留下还是走？8 道题亮出你的底牌》
- **钩子**：刷招聘软件到凌晨的你，缺的不是机会，是一个说得出口的答案。
- **人群与动机**：在职老师 + 泛职场人群（分享破圈到教师圈外，为平台拉新）。与《考编》同属决策系但题面更普适（不绑编制语境），**二选一：若担心与考编测同质化，可改为"年后跳槽季"节点款排后**。
- **8 题场景**：①周日晚上想到明天上班 ②收到猎头/招聘消息的第一反应 ③看到前同事的朋友圈 ④开会时领导画饼 ⑤工资倒挂新人 ⑥体检报告出来那一刻 ⑦下班后还有力气干什么 ⑧假如明天失业
- **结果人格（5）**：**骑驴找马实干派**（简历已读 3 遍，就差投）/ **围城钉子户**（嘴上想走，年假都用来续命）/ **时机未到修行者**（在攒筹码，不是在混日子）/ **果断斩断型**（说走就走，赔偿金算得比 HR 清）/ **叶公好龙型**（辞职信写了 8 版，一版没发）
- **视觉建议**：机票登机牌 / 辞职信便签风
- **风险**：与考编测题材相近，需在人格命名与场景上明显区隔（考编=体制围城，跳槽=市场流动）；建议排 P0-1 之后评估

### P1-1 《你的教师电量还剩几格？》【教师向共鸣款 / 节点运营】

- **标题变体**：《你的教师电量还剩几格？》/《开学第 8 周，你的电还撑得到寒假吗》/《8 道题，测测你的教坛续命指数》
- **钩子**：上辈子杀猪，这辈子教书？先别对号入座——测测是什么在偷偷给你充电。
- **人群与动机**：在职老师。职业倦怠共鸣（"不是我一个人这样"）+ 轻松自嘲可转发；适合**开学/期末节点投放**。
- **8 题场景**：①周一早上的闹钟 ②改到第 38 份同款错误 ③赶教案到凌晨 ④学生说"老师你今天好好看" ⑤办公室聊绩效方案 ⑥家长会被围住提问 ⑦放学后空教室 ⑧暑假第 3 天
- **结果人格（5）**：**满血卷王**（把内卷过成热血漫）/ **假期续命党**（支撑你的是倒计时，这也很科学）/ **电量告急·求充电**（你的累不是矫情，是长期满负荷）/ **佛系节能大师**（只烧该烧的火，只渡有缘的娃）/ **扫地僧**（最淡定的那个扛着最多悄悄话）
- **分享文案**："测完只剩 2 格电，谁来给我快充？"
- **导流**："给自己排一张有留白的课表"→ timetable.php；"少熬夜，课件直接用"→ course.php；课前小游戏当"教师省电模式"
- **视觉建议**：电池/充电 UI 语言 + 手绘教室涂鸦；结果页大电池可视化（电量格数即匹配度载体）

### P1-2 《测一测，你家到底该不该鸡娃？》【家长向立场款，谨慎】

- **标题变体**：《你家到底该不该鸡娃？》/《8 道题，算算你家的鸡娃性价比》/《鸡娃还是佛系？先测完再吵》
- **钩子**：报班、刷题、抢跑，还是放养、阅读、慢慢来？8 道题，给你家的教育投入做个体检。
- **人群与动机**：小学生家长。教育路线夫妻/两代人分歧 + 想要一份"第三方答案"当挡箭牌；评论区站队效应强。
- **8 题场景**：①孩子同桌报了 5 个班 ②家庭会议讨论暑假安排 ③孩子想学"没用"的爱好 ④期末排名出来 ⑤刷到"海淀妈妈的一天" ⑥存款 vs 培训班账单 ⑦写作业到十点没睡 ⑧孩子说"妈妈我想玩"
- **结果人格（5）**：**全面鸡娃型**（连寒假都是弯道）/ **静待花开型**（押注长线，顺便省下一辆代步车）/ **游击战家长**（该鸡鸡该放放）/ **预算有限心无限型**（钱花刀刃上，爱一分不少）/ **摇摆跟风型**（在家长群风向里反复横跳）
- **分享文案**："测完我家该'半鸡'，谁来监督执行？"
- **⚠️ 风险**：贩卖焦虑嫌疑。标题**必须**用"算性价比 / 体检"等理性词对冲；结果页出气口（"教育没有标准答案，适合你家的就是好答案"）加重；上线前 reviewer 单独审文案调性
- **视觉建议**：家庭账本 / 计算器风（理性对冲焦虑）

### P2-1 《测一测，你真的懂你家孩子吗？》【家长向温情款】

- **标题变体**：《你真的懂你家孩子吗？》/《8 道题，测出你和孩子的默契余额》/《别急着回答，你未必是最懂娃的人》
- **钩子**：朝夕相处 ≠ 真的了解。8 道生活小题，看看孩子心里的你和你以为的你差多远。
- **人群与动机**：家长。好奇心 + "我还能不懂我家孩子？"的胜负欲 + 测完想 @ 另一半（夫妻互测场景）。
- **8 题场景**：①孩子最想要的奖励 ②受委屈时的第一反应 ③偷偷藏起来的东西 ④最怕你说的那句话 ⑤最好的朋友 ⑥理想中的周末 ⑦考砸后最需要什么 ⑧他觉得你最常说的口头禅
- **结果人格（5）**：**心有灵犀型**（娃语十级翻译官）/ **身在心不在型**（同屋檐下，活在孩子的消息免打扰里）/ **用力过猛型**（把爱写成课表，孩子想要一个下午）/ **严慈错位型**（你以为立规矩，孩子以为下通牒）/ **默默守护型**（你不问，但都看见了，只是忘了说）
- **分享文案**："原来我不是最懂娃的人，有点扎心…"
- **导流**："陪娃玩一局课前小游戏当破冰"→ more.php#games；课件亲子共学；登录查看孩子真实学习记录（平台真价值）
- **备注**：偏温情、传播钩子弱于 P0/P1 各款，作为系列调性补位；愧疚转行动的转化文案是亮点，可反哺其他选题
