# 《测一测，你该不该考编？》趣味测评 H5 实施计划

## 目标

HUSTOJ 站内新增第二个趣味测评 H5（8 题单选 → 职业决策人格 → 结果页 + 分享卡片），从 `more.php#teacher` 卡片入口进入，用"人生决策外包"式好奇心钩子吸引老师（及有考编念头的家长）点进来测、转发。与《测一测你是哪位教育家》（teacher_style_test）构成"理想自我 → 现实出路"双测组合。本计划为编码输入。

## 背景 / 根因

第一个测评是"身份对标"钩子；调研结论：**决策钩子（"我要不要 X"）点击天花板更高**——用户把决策外包给测试，进来找一个"体面的理由"。淘宝/小红书 1 元情绪商品（"爱因斯坦的智力给我"）卖的是"被允许"：结果要替用户说出心里话。编制是教师圈永恒流量话题，情绪浓度高、天然适合甩进教师群。

## 已确认的需求决策（不得偏离）

- 主题：职业决策——考编 / 跳槽 / 原地开花；结果给的是**立场与建议**，不是伟人对标
- 纯前端浏览器本地计算；**无需登录**；不落库、不采集个人信息、无 DDL
- 视觉风格与第一个测评差异化：**解忧杂货铺 / 手写便签风，毒舌暖心**（不是绘本贴纸可爱风）；核心视觉锤 = **红印章立场徽章**
- 结果页大字输出立场印章：`该考！` / `再想想` / `别考！` / `不必考` / `先干着`
- 匹配度归一化到 70%~97%（给台阶）；结果页底部"仅供娱乐参考"
- 落地页静态数字"已有 **12653** 位老师测过"
- 转化区 3 个导流入口：课程表生成器（timetable.php）/ 课件（course.php）/ 课前小游戏（more.php#games），另加"登录解锁更多"轻提示（链接 loginpage.php）；导流口号："无论考不考编，先把眼前这届学生教好"
- UI：**frontend-design skill**（`.claude/skills/frontend-design/SKILL.md`，编码前先读，两遍工作法）；**移动端优先**（375~428px 主战场）
- 模板只改 syzoj；CSS 类名统一前缀 `cs-` 防冲突

### 题库（8 题 × 4 选项，隐藏权重，数据与页面分离）

场景与选项梗概（文案可微调，场景与主维度指向不变；每维度至少被 2 个选项触达、方向全局一致、无负分）：

1. **周五批完最后一本作业的心情**：A 终于批完了，寒暑假我来了(stability) / B 这堆错误对得起这份工资吗(pressure) / C 下周想试个新讲法，有点上头(love) / D 要不更新下简历试试水(risk)
2. **刷到"教师招聘报录比 50:1"的朋友圈**：A 点开公告研究岗位表(stability) / B 焦虑到多刷三套真题(decisive+stability) / C 关掉，与我无关(love/risk 分化) / D 转发并配文"一起卷"(pressure)
3. **工资条到手那一刻**：A 稳定就好，五险一金在涨(stability) / B 算了下房贷，沉默了(pressure) / C 无所谓，学生进步就是奖金(love) / D 打开招聘 App 瞄了一眼(risk)
4. **公开课被校长当众点评**：A 认真记笔记，这是考评材料(decisive+stability) / B 委屈，但忍了(pressure) / C 当场交流教学思路(love) / D 心里默默更新简历(risk)
5. **亲戚说"老师不是有寒暑假吗"**：A 微笑点头：是啊，编制内就是香(stability) / B 翻白眼算了懒得解释(pressure) / C 拉着亲戚安利学生趣事(love) / D 已经懒得接话，低头看机会(risk)
6. **难缠家长深夜 60 秒语音**：A 认真回复并留档，保护自己(decisive) / B 血压飙升，想辞职那一秒(pressure+risk) / C 先共情家长，再谈孩子(love) / D 静音明早再说，不值得内耗(稳定/低内耗指向 stability)
7. **前同事跳槽去大厂的朋友圈**：A 点赞，然后继续备课(love) / B 认真私聊求内推(risk) / C 对比自己的待遇，失眠(pressure) / D 研究对方路径，列行动计划(decisive+risk)
8. **假如明天不用上班**：A 睡到自然醒，追剧躺平(stability) / B 报个旅行团说走就走(risk) / C 回学校看看学生(love) / D 列一份"人生重启计划"但可能不会执行(qifen/低 decisive → pressure)

设计约束（同城市匹配测试 PRD）：每维度至少被 2 个选项触达（权重 ≥2）；同一维度权重方向全局一致；权重只存在数据文件，页面代码不感知数值。

### 匹配算法

答案 → 5 维偏好向量 → 与 5 人格画像向量算相似度 → min-max 归一化映射 **70%~97%**。Top1 = 主结果；Top2 = "你的隐藏第二人格"（小卡片 + 匹配度 + "换个答法，TA 可能会反超"，引诱重测）。

### 结果页结构（顺序固定）

1. **红印章立场徽章**（"该考！"等，盖章动效一次）+ 匹配度百分比环形动效（"编制人格匹配度"）
2. "你的职业底牌是——XX"（人格名 + epithet + emoji）
3. 3 标签 + 3 关键词胶囊
4. 金句区（"被允许"核心，引用样式）
5. 个性化理由 80~150 字（按得分最高 2~3 维从画像 desc 拼接，每维度 2 变体）
6. 五维能力雷达（SVG，复用 teacher_style_test 的雷达做法）
7. 第二人格小卡片
8. 转化区口号"无论考不考编，先把眼前这届学生教好" + 3 张导流卡片（课程表生成器 / 课件 / 课前小游戏）+ "登录解锁更多"轻提示
9. 操作区：生成分享卡片 / 重新测试
10. 底部"仅供娱乐参考"

### 分享卡片

前端 Canvas 生成 **750×1334** 竖版图：立场印章 + 人格称号 + 匹配度 + 3 标签 + 金句 + 钩子文案（"我测出来是【编制真香党】，该考！你是哪种？8 道题见分晓"）+ 平台名（$OJ_NAME）+ 二维码（指向测试页 URL，`template/syzoj/js/qrcode.min.js` 本地 vendor，参考 teacher_style_test.php 约 :774 用法）。支持长按/右键保存；微信内给"长按保存图片"引导语；生成后展示在页面内（toDataURL 图片）。

## UI 规格（解忧杂货铺 / 手写便签风 + frontend-design skill）

编码前先通读 `.claude/skills/frontend-design/SKILL.md`，按两遍工作法先产出设计 token 再写码。方向约束：

- **气质**：解忧杂货铺 + 手写便签——纸感底、便签卡、虚线撕边、轻微旋转的贴纸标签、红印章图章；毒舌暖心的语气（文案可以皮，但不刻薄）。**不是** SaaS 卡片模板风，**也不是**第一个测评的绘本贴纸可爱风。
- **色板**（可微调，禁止无理由换向）：纸底 `#F4F1EA`、墨字 `#28282A`、圆珠笔蓝 `#2F5DA8`、印章红 `#C8402F`、便签黄 `#F7D774`、薄荷 `#7FB8A2`、灰胶带 `#B9B2A6`。五人格各配一枚专属色。
- **字体**：系统圆润字重（`"PingFang SC","Microsoft YaHei"` 700/800），标题可做俏皮排版（印章字、描边、轻微旋转）；避免 frontend-design skill 列出的 AI 默认套路（奶油底+衬线+陶土橙、全大写 eyebrow、每节淡入上滑等）。
- **动效**：克制——单次编排（结果页印章"盖下"一击 + 匹配度环 + 一次礼花，复用 `game_confetti.js` 做法，失败静默降级）；答题过渡轻快；`prefers-reduced-motion` 降级。
- **移动端优先**：375px 起设计，触控目标 ≥44px，一屏一题；web 端居中限宽不做花活。
- **质量底线**：可见键盘焦点、对比度可读、`cs-` 类名前缀。

## 验收标准

- 全部验证步骤通过；无 BLOCKING 问题
- 模板只改 syzoj；游客白名单生效；无 SQL/CSRF/XSS 问题（动态输出统一 htmlentities，本页无用户输入入库）

- 移动端 375px 布局不破版；视觉符合解忧杂货铺/便签风规格，与第一个测评可区分
