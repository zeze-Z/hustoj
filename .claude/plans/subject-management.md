# 课程学科管理功能实现计划

## 目标
在管理后台添加课程学科（分类）管理功能，支持完整CRUD和排序

## 需求确认
- ✅ 功能范围：添加、编辑、删除、启用/禁用、拖拽排序
- ✅ 删除策略：有关联课程时禁止删除
- ✅ 菜单位置：课程管理分组下

## 现状分析
- `course_subject` 表存储学科信息：id, name, sort_order, status
- 课程列表页 course.php 使用该表展示学科Tab
- 管理后台已有课程管理，但无学科管理入口

## 实现方案

### 1. 新建文件（2个）

| 文件 | 功能 |
|------|------|
| admin/subject_manage.php | 学科管理页面（列表+添加+编辑一体化） |
| admin/subject_api.php | 统一AJAX接口（删除、状态切换、排序） |

### 2. 修改文件（1个）

| 文件 | 修改内容 |
|------|----------|
| admin/menu2.php | 课程管理分组下添加"学科管理"菜单项 |

### 3. 交互设计

**学科列表页（subject_list.php）**：
```
┌─────────────────────────────────────────────────────────────┐
│ [添加学科]                                                   │
├─────┬──────┬──────────────┬────────┬────────────────────────┤
│ 排序 │  ID  │     名称      │  状态  │         操作          │
├─────┼──────┼──────────────┼────────┼────────────────────────┤
│ ≡    │  1   │ 人工智能通识  │ ✅启用  │ 编辑 | 禁用 | 删除    │
│ ≡    │  2   │ 信息技术      │ ✅启用  │ 编辑 | 禁用 | 删除    │
│ ≡    │  3   │ 美术          │ ❌禁用  │ 编辑 | 启用 | 删除    │
└─────┴──────┴──────────────┴────────┴────────────────────────┘
```

### 4. 安全规范
- 权限：`$_SESSION[$OJ_NAME.'_'.'administrator']`
- CSRF：使用 `check_post_key.php`
- XSS：`htmlentities($str, ENT_QUOTES, 'UTF-8')`
- SQL：参数化查询

### 5. 验证清单
- [ ] 管理后台菜单显示正常
- [ ] 添加学科：名称校验（空值、重复）
- [ ] 编辑学科：名称校验（空值、重复、排除自身）
- [ ] 启用/禁用：状态即时切换
- [ ] 拖拽排序：排序保存成功
- [ ] 删除无关联学科：删除成功
- [ ] 删除有关联学科：提示无法删除

## 预计工作量
- 新建6个PHP文件
- 修改1个配置文件
