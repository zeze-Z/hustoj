# 20积分分批发放需求文档（定稿版）

**版本：** v1.0  
**日期：** 2026-07-24  
**状态：** 已评审，待开发  

---

## 一、背景

当前新用户注册一次性发放20积分，薅羊毛成本低。改为分批发放，提升用户留存和活跃度。

---

## 二、活动规则

| 规则 | 说明 |
|------|------|
| 参与对象 | 仅新注册用户，存量账户不参与 |
| 注册奖励 | 注册/激活即发 **6积分** |
| 连续登录奖励 | 连续登录7天再得 **14积分**：第1-6天每天2积分，第7天4积分 |
| 断签处理 | 中断后不再发放（`login_reward_status=2`，不是重置，是直接结束） |
| 注册当天 | 登录不额外发放 |
| 总计 | **20积分**（6 + 14） |

---

## 三、数据库变更

```sql
-- db/V2.3_20260724_login_streak.sql

ALTER TABLE `users`
ADD COLUMN `login_streak` INT NOT NULL DEFAULT 0 COMMENT '连续登录天数（新客签到活动用）',
ADD COLUMN `last_login_reward_date` DATE NULL DEFAULT NULL COMMENT '最后领取登录奖励日期',
ADD COLUMN `login_reward_status` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '0-进行中/未开始，1-已完成，2-已断签结束';

CREATE INDEX `idx_login_reward_date` ON `users`(`last_login_reward_date`);

-- 排除存量老用户（根据实际 created_at 字段调整时间）
UPDATE `users`
SET `login_reward_status` = 2
WHERE `created_at` < '2026-07-24 00:00:00';
```

> 若 `users` 表无 `created_at` 字段，需改用其他老用户判定条件。

## 四、登录奖励判定逻辑（修正后）

```
1. login_reward_status = 1 或 2 → 跳过
2. last_login_reward_date = CURDATE() → 跳过（今日已领）
3. registration_date = CURDATE() → 跳过（注册当天不额外发）
4. last_login_reward_date = 昨天 → streak += 1
5. last_login_reward_date = NULL → streak = 1（首次签到）
6. 否则且 streak > 0 → status = 2，断签结束
7. streak == 7 → 发4积分，status = 1
8. streak < 7 → 发2积分
9. 更新 last_login_reward_date = CURDATE()
```

### 关键修正（评审发现）

| 问题 | 修复 |
|------|------|
| 首次签到 streak 不 +1 | 首次签到时 `login_streak = 1` |
| 老用户无法与新用户区分 | 迁移脚本将存量用户 `login_reward_status` 置为 2 |
| 注册当天不额外发 | 增加 `registration_date == CURDATE()` 跳过判断 |

## 六、防刷措施

| 措施 | 说明 |
|------|------|
| 每日限1次 | `last_login_reward_date` 控制 |
| 同设备多账号 | 复用 `register_fingerprint`，登录页也采集指纹 |
| 注册当天不额外发 | `registration_date == CURDATE()` 跳过 |
| 断签即结束 | `login_reward_status=2` 持久化标记 |
| 风控阈值 | 同一指纹超过3个账号记录风控日志（第一阶段只记录不打断） |

## 八、老用户兼容

- `new_user_reward_claimed=1` 的存量用户不参与
- 新用户注册发6积分后，`new_user_reward_claimed` 置为1
- 存量用户通过迁移脚本 `login_reward_status=2` 排除

---

## 九、验收标准

1. 新用户注册得6积分
2. 连续登录7天：第1-6天每天2积分，第7天4积分
3. 断签后 `login_reward_status=2`，不再发放
4. 注册当天登录不额外发
5. 同一天多次登录不重复发
6. 存量用户不参与
7. 同设备多账号可记录风控日志
8. 登录奖励失败不影响正常登录
