# 注册功能优化需求文档

**版本**：V5
**更新日期**：2026-05-11
**目标**：吸引教师注册，通过激活邮件推广课件功能实现盈利

---

## 一、需求概述

| 角色 | 注册流程 | 说明 |
|------|----------|------|
| 教师 | 注册 → 激活邮件 → 激活账号 → 后台审核权限 → 获得教师功能 | 教师权限需后台授予，不能自主上传课件 |
| 学生 | 注册 → 激活邮件 → 激活账号 → 自动获得学生功能 | 与教师流程一致，不简化 |

**核心卖点**：课件管理 + 在线作业 + 学生管理 + 收益分成

---

## 二、改动清单

### 改动点 1：注册页面
**文件**：`template/syzoj/registerpage.php`

| 改动项 | 现状 | 改为 |
|--------|------|------|
| 角色选择 | 无 | 单选框：○ 我是一名教师 / ○ 我是一名学生 |
| 邮箱提示 | "用QQ邮箱可得QQ头像" | "请填写真实邮箱，用于接收账号激活通知" |
| 页面引导文案 | 无 | 顶部加平台简介，突出教师专属功能 |
| 必填校验 | 仅 school_id 有 required | 所有必填字段加 `required` 属性 |

**必填字段列表**：
- user_id（用户名）
- nick（昵称）
- password（密码）
- rptpassword（确认密码）
- school_id（学校）
- email（邮箱）
- vcode（验证码，开启时）
- role（角色选择）

### 改动点 2：注册逻辑 + 数据库
**文件**：`register.php` + `users` 表

**数据库改动**：新增 `role` 字段

```sql
ALTER TABLE `users` ADD COLUMN `role` VARCHAR(20) NOT NULL DEFAULT 'student' COMMENT '用户角色：teacher/student' AFTER `school_id`;
```

**register.php 改动**：

| 改动项 | 说明 |
|--------|------|
| 接收 `role` 参数 | 从 POST 获取 `role`（teacher/student），默认 student |
| 飞书通知区分 | 教师 → "🔔 教师入驻"，学生 → "新用户注册（学生）" |
| 角色写入 | 存入新增的 `role` 字段 |

### 改动点 4：邮箱唯一性校验
**文件**：`register.php`

| 改动项 | 现状 | 改为 |
|--------|------|------|
| 邮箱重复检查 | 仅限制 1 小时内重复注册 | 新增邮箱永久唯一性校验 |
| 已注册邮箱提示 | 无 | 页面提示"该邮箱已注册，请直接登录"，并提供登录链接 |

**逻辑**：在插入数据库前，查询 `users` 表，如邮箱已存在，直接 alert 提示并返回，不插入数据。

## 三、改动文件汇总

| 文件 | 改动内容 |
|------|----------|
| `template/syzoj/registerpage.php` | 加角色单选、改邮箱提示、加引导文案、加 required 校验 |
| `register.php` | 接收 role、发不同邮件、飞书通知区分、邮箱唯一性校验 |
| 数据库 | `users` 表新增 `role` 字段 |
| `admin/privilege_add.php` | 参考邮件模板（仅参考，不改） |

**无需改动的文件**：
- `feishu_notify.php`（逻辑不变，只改调用参数）
- `school.php`（学校导入走管理端）
