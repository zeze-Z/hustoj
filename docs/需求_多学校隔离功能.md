# HUSTOJ 多学校隔离功能需求文档

## 1. 项目背景

当前 HUSTOJ 系统所有用户共享同一套数据，无法按学校区分用户可见内容。为满足多学校推广需求，需要实现基于学校的数据隔离机制。

## 2. 目标

实现学校维度的数据隔离，让不同学校的师生只能看到本校数据，同时支持超级管理员统筹管理。

## 3. 功能需求

### 3.1 学校管理

#### 3.1.1 学校数据模型
```
school 表
- id: 学校ID (主键)
- name: 学校名称
- code: 学校代码（唯一，用于标识）
- status: 状态 (0=禁用, 1=启用)
- created_at: 创建时间
- updated_at: 更新时间
```

#### 3.1.2 超级管理员功能
- 添加/编辑/禁用学校
- 查看所有学校列表
- 为每个学校设置可访问的公共题目/比赛

### 3.2 用户与学校关联

#### 3.2.1 用户表扩展
```
users 表新增字段
- school_id: 所属学校ID (外键，关联 school 表)
```

#### 3.2.2 注册流程
1. **老师注册**：
   - 选择学校（从预设列表）
   - 填写基本信息
   - 注册后默认拥有学校管理员权限
   
2. **学生注册**：
   - 选择学校（从预设列表）
   - 填写基本信息
   - 注册后为学生权限

#### 3.2.3 现有用户迁移
- 所有现有用户的 school_id 统一设置为"成都东辰"
- 需要预先在 school 表中创建"成都东辰"记录

### 3.3 数据隔离规则

#### 3.3.1 完全隔离的数据（按学校过滤）
| 数据类型 | 隔离规则 |
|---------|---------|
| 用户列表 | 只显示同校用户 |
| 排名榜 | 只显示同校用户排名 |
| 提交记录 | 只显示同校用户提交 |
| 讨论区 | 只显示同校用户发帖 |
| 班级/作业 | 只显示本校创建的 |

#### 3.3.2 可配置共享的数据
| 数据类型 | 规则 |
|---------|------|
| 题目 | 默认本校可见，超级管理员可设置"所有学校可见" |
| 比赛 | 默认本校可见，超级管理员可设置"所有学校可见" |
| 新闻公告 | 默认本校可见，超级管理员可设置"所有学校可见" |

#### 3.3.3 数据表扩展
```
problem 表新增字段
- is_public: 是否对所有学校公开 (0=否, 1=是)
- school_id: 创建学校ID

contest 表新增字段
- is_public: 是否对所有学校公开 (0=否, 1=是)
- school_id: 创建学校ID

news 表新增字段
- is_public: 是否对所有学校公开 (0=否, 1=是)
- school_id: 创建学校ID
```

### 3.4 权限体系

#### 3.4.1 角色定义
| 角色 | 权限 |
|-----|------|
| 超级管理员 | 管理所有学校、查看所有数据、设置公共数据 |
| 学校管理员（老师） | 管理本校用户、创建本校题目/比赛、查看本校数据 |
| 学生 | 查看本校数据、提交代码、参与本校比赛 |

#### 3.4.2 数据访问控制
```php
// 核心过滤逻辑
function getSchoolFilter() {
    global $OJ_SCHOOL_MODE;
    
    if (!$OJ_SCHOOL_MODE) return ''; // 未开启学校模式
```

## 4. 技术方案

### 4.1 数据库变更

> 基础表结构文件：`trunk/install/jol_full_structure-20260317.sql`
> 后续表结构变更在此文件基础上修改

```sql
-- ============================================
-- 多学校隔离功能 - 数据库变更脚本
-- 基于 jol_full_structure-20260317.sql
-- ============================================

-- 1. 创建学校表
CREATE TABLE `school` (
  `id` int NOT NULL AUTO_INCREMENT,
  `name` varchar(100) NOT NULL COMMENT '学校名称',
  `code` varchar(50) NOT NULL COMMENT '学校代码',
  `status` tinyint NOT NULL DEFAULT '1' COMMENT '状态:0禁用,1启用',
  `created_at` datetime DEFAULT CURRENT_TIMESTAMP,
  `updated_at` datetime DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `code` (`code`)
) ENGINE=MyISAM DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;

-- 2. 初始化成都东辰学校（ID=1）
INSERT INTO `school` (`id`, `name`, `code`, `status`) VALUES 
(1, '成都东辰', 'chengdu_dongchen', 1);

-- 3. 用户表扩展
-- 现有 school 字段为 varchar(20)，扩展为 varchar(100)
-- 新增 school_id 关联学校表
ALTER TABLE `users` 
  MODIFY COLUMN `school` varchar(100) NOT NULL DEFAULT '' COMMENT '学校名称(冗余)',
  ADD COLUMN `school_id` int DEFAULT NULL COMMENT '所属学校ID' AFTER `school`,
  ADD KEY `idx_school_id` (`school_id`);

-- 4. 迁移现有用户到成都东辰
UPDATE `users` SET `school_id` = 1, `school` = '成都东辰' WHERE `school_id` IS NULL;

-- 5. 题目表扩展
ALTER TABLE `problem` 
  ADD COLUMN `school_id` int DEFAULT NULL COMMENT '创建学校ID' AFTER `source`,
  ADD COLUMN `is_public` tinyint NOT NULL DEFAULT '0' COMMENT '是否公开:0否,1是' AFTER `school_id`,
  ADD KEY `idx_school_id` (`school_id`);

-- 6. 比赛表扩展
ALTER TABLE `contest` 
  ADD COLUMN `school_id` int DEFAULT NULL COMMENT '创建学校ID' AFTER `user_id`,
  ADD COLUMN `is_public` tinyint NOT NULL DEFAULT '0' COMMENT '是否公开:0否,1是' AFTER `school_id`,
  ADD KEY `idx_school_id` (`school_id`);

-- 7. 新闻表扩展
ALTER TABLE `news` 
  ADD COLUMN `school_id` int DEFAULT NULL COMMENT '创建学校ID' AFTER `defunct`,
  ADD COLUMN `is_public` tinyint NOT NULL DEFAULT '0' COMMENT '是否公开:0否,1是' AFTER `school_id`,
  ADD KEY `idx_school_id` (`school_id`);

-- 8. 现有题目/比赛/新闻默认归属成都东辰并公开
UPDATE `problem` SET `school_id` = 1, `is_public` = 1 WHERE `school_id` IS NULL;
UPDATE `contest` SET `school_id` = 1, `is_public` = 1 WHERE `school_id` IS NULL;
UPDATE `news` SET `school_id` = 1, `is_public` = 1 WHERE `school_id` IS NULL;
```

```php
// include/school.php

// 获取当前用户学校ID
function getCurrentUserSchoolId() {
    global $OJ_NAME;
    if (!isset($_SESSION[$OJ_NAME.'_'.'user_id'])) return null;
    // 从session或数据库获取
    return $_SESSION[$OJ_NAME.'_'.'school_id'] ?? null;
}

// 检查是否超级管理员
function isSuperAdmin() {
    global $OJ_NAME;
    return isset($_SESSION[$OJ_NAME.'_'.'administrator']);
}

// 获取SQL过滤条件
function getSchoolSQLFilter($tableAlias = '') {
    global $OJ_SCHOOL_MODE;
    
    if (!$OJ_SCHOOL_MODE) return '';
    if (isSuperAdmin()) return '';
    
    $prefix = $tableAlias ? $tableAlias . '.' : '';
    $school_id = getCurrentUserSchoolId();
    
    if (!$school_id) return " AND {$prefix}school_id IS NULL";
    
    return " AND ({$prefix}school_id = $school_id OR {$prefix}is_public = 1)";
}
```
