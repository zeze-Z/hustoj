# 竞赛真题 - 需求文档

**版本**：v3.0
**日期**：2026-04-16
**状态**：待确认
**负责人**：小陈

---

## 一、需求背景

在OJ平台中增加「竞赛真题」模块，吸引备考学生和家长：
- 收集蓝桥杯、CSP-J/S、GESP等竞赛历年真题
- 学生可以自由练习真题，不限时、不排名
- 按竞赛来源、难度筛选，快速找到想做的题目

---

## 二、核心决策（已确认）

| # | 决策 | 说明 |
|---|------|------|
| ✅ 1 | **不复用独立菜单** | 直接用现有的「竞赛&作业」菜单，改名为「竞赛真题」 |
| ✅ 2 | **真题放题库不放比赛** | 题目录入到「问题管理」，打上竞赛来源标签，学生去题库筛选 |
| ✅ 3 | **不改评测系统** | 复用现有评测队列（C++/Java/Python已支持） |
| ✅ 4 | **不需要Scratch** | 只支持 C++/Java/Python |
| ✅ 5 | **网上找题目** | 首批题目从网上（蓝桥杯等）批量导入 |
| ✅ 6 | **学校隔离复用** | 复用现有 `school_id` / `is_public` 隔离逻辑 |

## 六、学校隔离（复用）

复用现有的 `include/school.php` 隔离逻辑：

| 场景 | 隔离规则 |
|------|---------|
| 题库浏览 | 所有公开题目均可看（无隔离） |
| 竞赛管理 | 只能看到本校创建的比赛 + 公开比赛 |
| 竞赛真题 | 不涉及比赛，题库无隔离，直接展示 |

> **说明**：竞赛真题作为题库的一部分，不涉及学校隔离。如果后续需要"本校专属题单"功能，可复用 `school_id` 字段。
