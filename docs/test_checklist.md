## 测试用例示例

### 用户A注册流程
1. 打开注册页面
2. 填写 user_id=test001, password=xxx, email=test@xxx.com
3. 学校选择「成都东辰」
4. 提交注册
5. 数据库查询：`SELECT * FROM users WHERE user_id='test001'`
6. 验证 school_id 和 school 字段正确

### 提交记录隔离测试
1. 用学校A账号登录
2. 访问 /status.php
3. 查看提交记录列表
4. 验证只有本校用户的提交

### 题目隔离测试
1. 用学校A账号登录
2. 访问 /problemset.php
3. 访问 /problem.php?id=xxx (本校题目) - 应显示
4. 访问 /problem.php?id=yyy (其他学校非公开题目) - 应无权限

## 预期结果

### 开启学校模式 ($OJ_SCHOOL_MODE = true)
- 非超管用户只能看到：本公司数据 + 标记为公开的数据
- 超管可以看到所有数据

### 关闭学校模式 ($OJ_SCHOOL_MODE = false)
- 所有用户看到所有数据（原有行为）
