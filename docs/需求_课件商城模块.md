# 需求文档：HUSTOJ 课件商城模块

**版本：** v1.6  
**日期：** 2026-03-30  
**状态：** 草稿

---

## 一、需求背景

基于 HUSTOJ 平台搭建课程教育体系，面向学校教师提供付费课程资源。教师可在平台上浏览课程体系、查看课件与教案预览，购买单课后通过邮件获取完整资源下载链接。

当前上架**人工智能通识课程**，后期扩展其他学科课程。

---

## 二、目标用户

| 角色 | 说明 |
|------|------|
| **普通用户（教师）** | 学校教师，主要购买方，需注册登录后购买 |
| **administrator** | 系统管理员，负责课程管理、订单管理，复用现有权限体系 |

---

## 三、课程体系结构

按**学科 → 课程**两级层次组织，课程通过**标签**进行分类标注：

```
人工智能通识课程
  └── 第1课：什么是人工智能  [标签：入门, Python]
  └── 第2课：机器学习初探    [标签：入门, 机器学习]
  └── 第3课：图像识别        [标签：进阶, 计算机视觉]

信息技术课程
  └── ...

美术课程
  └── ...

音乐课程
  └── ...
```

- 所有学校统一可见，不做学校隔离
- 支持免费课程和付费课程
- 每门课程独立定价，按单课购买
- 标签存储在课程表 tags 字段，逗号分隔
- 课程展示顺序由 administrator 手动调整

---

## 四、课程内容组成

每门课程包含以下两类资源：

| 资源类型 | 格式 | 说明 |
|----------|------|------|
| **课件** | PPT / PDF | 课堂教学使用，含金山文档预览 |
| **教案** | Word / PDF | 教学参考，含金山文档预览 |

- **预览**：通过金山文档嵌入 iframe 实现直接预览，无需下载
- **完整下载**：存储于**百度网盘**，平台保存链接+提取码，邮件发送给购买方
- **链接有效期**：默认 1 年（365 天），写死在代码中

## 五、功能模块详细说明

### 5.1 课程列表与体系展示

- 顶部 Tab 按**学科**切换
- 课程以卡片形式展示，支持按**标签**筛选
- 每门课程卡片展示：课程名称、标签、课时数、价格、购买状态
- 免费课程显示「免费获取」按钮，付费课程显示「立即购买」按钮
- 课程展示顺序按 sort_order 排列
- 未登录用户可浏览课程列表，但无法查看预览和购买

### 5.2 课程详情页

- 展示课程基本信息（名称、所属学科、标签、课时数、简介、价格）
- **课件预览**：金山文档 iframe 嵌入，直接在页面预览
- **教案预览**：金山文档 iframe 嵌入，直接在页面预览
- 已获取用户：显示"重新获取下载链接"按钮（触发重发邮件）
- 未获取用户：
  - 免费课程：显示「免费获取」按钮
  - 付费课程：显示「立即购买」按钮

### 5.3 购买与支付

#### 免费课程流程
- 用户点击「免费获取」
- 确认收件邮箱（默认使用账号注册邮箱，可修改）
- 点击确认后直接生成订单并发送邮件，无需支付

#### 付费课程流程
- 用户点击「立即购买」后进入购买页面
- 填写/确认收件邮箱（默认使用账号注册邮箱，可修改）
- 支付方式：接入 **YunGouOS** 三方支付平台，支持微信支付 / 支付宝
- 支付成功后自动生成订单记录并发送邮件
- 同一用户重复获取同一课程时，提示已获取并引导重新发送邮件

### 5.4 课件自动交付（邮件）

- 获取成功后（免费课程点击确认，付费课程支付成功），系统**自动发送邮件**
- 邮件内容包含：
  - 课程名称
  - 课件百度网盘下载链接 + 提取码 + 有效期说明
  - 教案百度网盘下载链接 + 提取码 + 有效期说明
  - 版权与使用条款提示
- 邮件发送失败时，系统记录失败状态，administrator 可手动重发

### 5.5 我的获取记录（用户端）

- 入口：主页右侧账号下拉菜单
- 展示已获取课程列表：课程名称、价格、获取时间、邮件发送状态
- 每条记录提供"重新获取下载链接"按钮（触发重发邮件）
- 支持分页展示

### 5.6 订单管理（管理端）

- 订单列表：展示所有订单，支持按状态、课程、时间筛选
- 订单详情：用户信息、课程、金额、支付时间、邮件发送状态
- 手动重发邮件：针对邮件发送失败的订单，administrator 可手动触发重发
- 订单统计：按课程、时间段汇总销售数量和金额

### 5.7 课程管理（管理端）

- 新增 / 编辑 / 下架课程
- 填写课程信息：名称、所属学科、标签（逗号分隔）、课时数、简介、价格（0=免费）
- 填写金山文档预览链接（课件 + 教案）
- 填写百度网盘链接 + 提取码（课件 + 教案）
- 填写链接到期时间（link_expire_date，百度网盘链接到期时间，方便管理端查看）
- **调整课程展示顺序**：拖拽排序或手动填写 sort_order

## 六、核心业务流程

### 免费课程
```
用户登录 → 浏览课程 → 详情页预览 → 点击「免费获取」
  → 确认邮箱 → 直接发送邮件（含网盘链接+提取码）
  → 用户收到邮件 → 下载课件和教案
```

### 付费课程
```
用户登录 → 浏览课程 → 详情页预览 → 点击「立即购买」
  → 确认邮箱 → YunGouOS 支付
  → 支付成功 → 自动发送邮件（含网盘链接+提取码）
  → 用户收到邮件 → 下载课件和教案
```

## 七、数据库设计

### 1. 课程学科表 `course_subject`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK | 学科ID |
| name | VARCHAR | 学科名称（信息技术、人工智能通识、美术、音乐） |
| sort_order | INT | 排序权重 |
| status | TINYINT | 状态：1启用 0禁用 |

### 2. 课程表 `course`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK | 课程ID |
| title | VARCHAR | 课程名称 |
| subject_id | INT FK | 所属学科ID |
| tags | VARCHAR | 标签（逗号分隔，如：入门,Python） |
| lesson_count | INT | 课时数 |
| description | TEXT | 课程简介 |
| price | DECIMAL(10,2) | 价格（0=免费） |
| status | TINYINT | 状态：1上架 0下架 |
| courseware_preview_url | VARCHAR | 课件金山文档预览链接 |
| lesson_plan_preview_url | VARCHAR | 教案金山文档预览链接 |
| courseware_link | VARCHAR | 课件百度网盘下载链接 |
| courseware_code | VARCHAR | 课件百度网盘提取码 |
| lesson_plan_link | VARCHAR | 教案百度网盘下载链接 |
| lesson_plan_code | VARCHAR | 教案百度网盘提取码 |
| link_expire_date | DATE | 百度网盘链接到期时间（管理端查看用） |
| sort_order | INT | 展示排序权重 |
| created_at | DATETIME | 创建时间 |

### 3. 订单表 `course_order`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK | 订单ID |
| order_no | VARCHAR | 订单号（唯一） |
| user_id | VARCHAR FK | 购买用户ID（关联 users 表） |
| course_id | INT FK | 课程ID |
| amount | DECIMAL(10,2) | 支付金额（免费课程为0） |
| email | VARCHAR | 收件邮箱 |
| pay_status | TINYINT | 0待支付 1已支付 |
| pay_time | DATETIME | 支付时间 |
| pay_channel | VARCHAR | 支付渠道（yungouos_wx / yungouos_alipay / free） |
| mail_status | TINYINT | 0未发送 1已发送 2发送失败 |
| mail_sent_at | DATETIME | 邮件发送时间 |
| created_at | DATETIME | 创建时间 |

## 八、技术要点

| 项目 | 说明 |
|------|------|
| **预览** | 金山文档 iframe 嵌入，无需登录即可预览 |
| **支付** | 接入 YunGouOS，支持微信支付 / 支付宝，需处理支付回调（notify_url） |
| **邮件发送** | 复用现有 PHPMailer，获取成功后触发自动发送 |
| **课件存储** | 百度网盘，平台保存链接+提取码，不存储文件 |
| **防盗链** | 完整下载链接仅通过邮件发送，不在前端页面暴露 |
| **重复获取** | 订单表唯一索引（user_id + course_id），前端提示已获取 |
| **有效期** | 写死在代码中，默认 365 天，邮件中展示 |
| **课程排序** | sort_order 字段，管理端支持拖拽或手动调整 |
| **权限控制** | 管理端页面复用现有 administrator 权限校验逻辑 |
