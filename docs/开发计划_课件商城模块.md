# 开发计划：HUSTOJ 课件商城模块

**版本：** v1.0  
**日期：** 2026-03-31

---

## 开发阶段拆分

### 阶段一：数据库 + 基础框架
**目标：** 建表 + 管理端课程列表（只读）

**任务：**
1. 创建 3 张表（course_subject、course、course_order）
2. 初始化 4 个学科数据（信息技术、人工智能通识、美术、音乐）
3. 管理端课程列表页（基础展示，无编辑功能）

**安全要点：**
- 所有管理端页面检查 `administrator` 权限
- SQL 参数化查询，防止注入
- XSS 过滤（课程名称、简介等用户输入）

---

### 阶段二：课程管理（CRUD）
**目标：** 管理端可新增、编辑、删除、排序课程

**任务：**
1. 新增课程页
2. 编辑课程页
3. 下架/上架功能
4. 排序功能（拖拽或手动）

**安全要点：**
- 表单验证：价格必须 ≥0，链接格式校验
- 文件不落地：只存链接，不上传文件
- **CSRF 防护：复用现有 `csrf_check.php`**（POST 表单加 csrf token）
- 权限校验：确保只有 administrator 可操作

---

### 阶段三：用户端课程展示 + 预览
**目标：** 用户可浏览课程、预览课件教案

**任务：**
1. 课程列表页（Tab 切换学科 + 标签筛选）
2. 课程详情页
3. 金山文档 iframe 预览

**安全要点：**
- iframe 加 `sandbox` 属性限制权限
- 预览链接必须是 kdocs.cn 域名，防止钓鱼
- 未登录用户点击获取按钮跳转登录页
- XSS 过滤标签显示

---

### 阶段四：免费课程获取 + 邮件发送
**目标：** 免费课程可直接获取，邮件发送下载链接

**任务：**
1. 获取页（邮箱确认）
2. 生成订单（pay_channel=free，pay_status=1）
3. 发送邮件（复用 PHPMailer）
4. 我的获取页
5. 订单管理页（基础展示）

**安全要点：**
- 邮箱格式校验（正则表达式）
- 同一用户同一课程只能获取一次（唯一索引 user_id + course_id）
- **CSRF 防护：获取表单加 csrf token**
- 邮件内容不过多暴露内部信息
- 发送频率限制（防止刷邮件，建议 1 分钟内同一用户同一课程只能发一次）
- 邮件发送失败记录日志，便于排查

---

### 阶段五：付费课程 + YunGouOS 支付
**目标：** 接入支付，完成付费课程购买流程

**任务：**
1. YunGouOS 支付接入（获取 API 密钥、配置回调地址）
2. 支付页面（选择支付方式）
3. 支付回调处理（/course/notify）
4. 支付成功后触发邮件
5. 订单管理页完善（筛选、统计、手动重发）

**安全要点：**
- 支付回调验签（验证请求来自 YunGouOS，防止伪造）
- 订单金额与课程价格比对，防止篡改
- 回调日志记录，便于排查问题
- 支付状态幂等处理（避免重复发货，同一订单多次回调只处理一次）
- 支付超时处理（订单 30 分钟未支付自动取消）

## 通用安全规范

### 权限校验
- 所有管理端页面顶部检查 `administrator` 权限
- 用户端页面检查登录状态（需要时）

### 输入校验
- 所有用户输入都要校验（长度、格式、类型）
- 数据库查询使用参数化查询（PDO prepared statement）

### 输出转义
- 所有输出到 HTML 的用户数据都要 htmlspecialchars() 转义
- JSON 响应设置 Content-Type: application/json

### 日志记录
- 重要操作记录日志（新增课程、支付回调、邮件发送等）
- 错误信息不要暴露内部细节给用户

### 错误处理
- 捕获异常，返回友好的错误提示
- 不要在前端显示 SQL 错误、文件路径等敏感信息

---

## 代码规范

- 复用现有 HUSTOJ 代码风格和函数
- 使用 PDO 进行数据库操作
- 表单使用 csrf_check.php 防护
- 邮件使用现有 PHPMailer 类
