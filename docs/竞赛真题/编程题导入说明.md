# 编程题批量导入说明
## 支持格式
1. **FPS XML格式**（推荐，系统原生支持，包含完整题目信息）
2. 支持SYZOJ、Hydro、QDUOJ等多种主流OJ导出格式

## 使用方法
1. 登录管理后台 → 进入「题目导入」页面
2. 选择对应格式的导入入口，上传XML/ZIP文件即可
3. 导入的题目会自动包含题面、测试用例、时间内存限制、来源等完整信息

## 模板说明
`编程题批量导入模板(FPS格式).xml` 是标准FPS格式模板，包含2道示例题目，可以直接测试导入，也可以按照格式新增更多题目。
### 字段说明
- `title`：题目标题
- `time_limit`：时间限制，单位秒
- `memory_limit`：内存限制，单位MB
- `description`：题目描述，支持HTML
- `input`：输入描述
- `output`：输出描述
- `sample_input`/`sample_output`：样例输入输出
- `hint`：提示/说明
- `source`：标签/分类（支持竞赛来源+知识点标签，多个用空格分隔，如"GESP 一级 真题 排序"）
- `test_input`/`test_output`：测试用例输入输出，多个用例换行分隔
- `difficulty`：难度：1简单/2中等/3困难

## 注意事项
- 测试用例输入输出要严格一一对应，顺序不能错
- 可以把多个题目XML文件打包成ZIP批量导入
- 导入前建议先备份现有题库数据
