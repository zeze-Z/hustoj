# 编程题批量导入说明

## 支持格式

1. **FPS XML格式**（推荐，系统原生支持，包含完整题目信息）
2. 支持 SYZOJ、Hydro、QDUOJ 等多种主流 OJ 导出格式

## 使用方法

1. 登录管理后台 → 进入「题目导入」页面
2. 选择 FPS(.xml)/ZIP(.xml inside) 导入入口，上传 XML/ZIP 文件
3. 导入的题目会包含题面、测试用例、时间内存限制、来源等信息
4. 导入后如需让普通用户在题库中练习，请在「问题管理」中将题目状态切换为「启用」

## 模板说明

`编程题批量导入模板(FPS格式).xml` 是标准 FPS 格式模板，包含 2 道示例题目，可以直接测试导入，也可以按照格式新增更多题目。

### 字段说明

- `title`：题目标题
- `time_limit`：时间限制，单位秒
- `memory_limit`：内存限制，单位 MB
- `description`：题目描述，支持 HTML/CDATA
- `input`：输入描述
- `output`：输出描述
- `sample_input`/`sample_output`：样例输入输出
- `hint`：提示/说明
- `source`：标签/分类（支持竞赛来源 + 知识点标签，多个用空格分隔，如 `GESP-2025.12 一级 条件判断`）
- `difficulty`：预留难度字段；当前 HUSTOJ FPS 导入器可能不会自动写入 `problem.level`，导入后请在管理端确认难度
- `test_input`/`test_output`：测试数据

## 测试数据写法（重要）

HUSTOJ FPS 导入器的规则是：

- 一个 `<test_input>` 节点会生成一个 `.in` 测试输入文件
- 一个 `<test_output>` 节点会生成一个 `.out` 测试输出文件
- 导入器不会自动把多行内容拆分成多个测试点

因此，**单组输入题目的多个测试点应写成多个同名配对节点**：

```xml
<test_input name="test1"><![CDATA[1 2]]></test_input>
<test_output name="test1"><![CDATA[3]]></test_output>

<test_input name="test2"><![CDATA[3 4]]></test_input>
<test_output name="test2"><![CDATA[7]]></test_output>
```

只有当题目本身要求「多组输入」或「读到 EOF」时，才应把多组数据写在同一个 `<test_input>` 中，并在题面中明确说明。

## 注意事项

- `test_input` 和 `test_output` 的 `name` 建议保持一致（如 `test1` / `test1`）
- 测试用例输入输出要严格一一对应
- 可以把多个题目 XML 文件打包成 ZIP 批量导入
- 导入前建议先备份现有题库数据
