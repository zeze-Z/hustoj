### 编程题（共2题，共50分）

#### 编程题1：等差矩阵
**提交入口**：[洛谷 B4259](https://www.luogu.com.cn/problem/B4259)

构造 `n` 行 `m` 列矩阵，使每行每列均为等差数列。第 `i` 行第 `j` 列填入 `(i-1)*m+(j-1)` 即满足要求。

```
输入：3 4
输出：
1 2 3 4
2 4 6 8
3 6 9 12
```

**参考代码（C++）**：
```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n, m; cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++)
            cout << (i-1)*m + (j-1) << (j==m?'\n':' ');
    }
    return 0;
}
```
