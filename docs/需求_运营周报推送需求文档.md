# OJ平台运营周报推送需求文档

## 一、需求概述

每周一0点通过cron定时任务自动推送运营周报至飞书，帮助运营人员掌握平台核心数据。

## 二、推送时间

- **推送时间**：每周一 00:00
- **触发方式**：Linux cron定时任务
- **数据周期**：上周一 00:00 至 上周日 23:59:59

## 三、推送内容

```
📊 OJ平台运营周报（2026.05.05 - 2026.05.11）

👤 用户活跃
• 本周登录：XXX人
• 本周提交题目：XXX人（XXX次，通过率XX%）
• 新增注册：XXX人

🎮 游戏热度（本周访问次数）
• AI猜画：XXX次
• 编程启蒙：XXX次
• 汉字打字：XXX次
• 数学闯关：XXX次
• 卡片配对：XXX次

📚 课件运营
• 本周订单：X单（¥XXX.XX）
• 课件浏览TOP3：
  1. XXX（XXX次）
  2. XXX（XXX次）
  3. XXX（XXX次）
• 热销课件TOP3：
  1. XXX（X单）
  2. XXX（X单）
  3. XXX（X单）

⚠️ 安全概况
• 登录失败：XXX次
```

## 四、数据源

| 指标 | 数据表/日志 | 查询条件 |
|------|-------------|----------|
| 本周登录人数 | loginlog | password='login ok', time在上周范围内 |
| 本周提交人数/次数 | solution | in_date在上周范围内 |
| 新增注册 | users | reg_time在上周范围内 |
| 本周订单 | course_order | pay_status=1, created_at在上周范围内 |
| 热销课件 | course + course_order | 按course_id分组统计订单数 |
| 游戏访问次数 | Nginx访问日志 | 解析`*_game.php`访问记录 |
| 课件浏览次数 | Nginx访问日志 | 解析`course_info.php?id=X`访问记录 |
| 登录失败 | loginlog | password='login fail', time在上周范围内 |

### 5.2 核心代码

```php
<?php
/**
 * OJ平台运营周报推送脚本
 * 执行方式：php operation_weekly_report.php
 * 定时配置：0 0 * * 1 cd /home/judge/src/web && php include/operation_weekly_report.php >> /var/log/hustoj/weekly_report.log 2>&1
 */

require_once(dirname(__FILE__)."/db_info.inc.php");
require_once(dirname(__FILE__)."/feishu_notify.php");

// 配置项：Nginx访问日志路径
$OJ_NGINX_ACCESS_LOG = '/var/log/nginx/access.log';

/**
 * 发送运营周报
 */
function send_weekly_report() {
    global $OJ_NGINX_ACCESS_LOG;
    
    // 计算上周时间范围
    $last_monday = date('Y-m-d', strtotime('last monday', strtotime('yesterday')));
    $last_sunday = date('Y-m-d', strtotime('last sunday', strtotime('yesterday')));
    
    // 1. 用户活跃数据（SQL查询）
    $login_users = pdo_query(
        "SELECT COUNT(DISTINCT user_id) as cnt FROM loginlog 
         WHERE password='login ok' AND DATE(time)>=? AND DATE(time)<=?",
        $last_monday, $last_sunday
    )[0]['cnt'];
    
    $submit = pdo_query(
        "SELECT COUNT(DISTINCT user_id) as users, COUNT(*) as total,
                SUM(CASE WHEN result=4 THEN 1 ELSE 0 END) as passed
         FROM solution WHERE DATE(in_date)>=? AND DATE(in_date)<=?",
        $last_monday, $last_sunday
    )[0];
    $pass_rate = $submit['total'] > 0 ? round($submit['passed']/$submit['total']*100) : 0;
    
    $new_users = pdo_query(
        "SELECT COUNT(*) as cnt FROM users WHERE DATE(reg_time)>=? AND DATE(reg_time)<=?",
        $last_monday, $last_sunday
    )[0]['cnt'];
    
    // 2. 游戏热度（Nginx日志解析）
    $game_stats = parse_nginx_log($OJ_NGINX_ACCESS_LOG, $last_monday, $last_sunday);
    
    // 3. 课件运营数据（SQL查询）
    $orders = pdo_query(
        "SELECT COUNT(*) as cnt, SUM(amount) as amount FROM course_order 
         WHERE pay_status=1 AND DATE(created_at)>=? AND DATE(created_at)<=?",
        $last_monday, $last_sunday
    )[0];
    
    $top_courses = pdo_query(
        "SELECT c.title, COUNT(co.id) as order_count
         FROM course c
         LEFT JOIN course_order co ON c.id=co.course_id AND co.pay_status=1
         WHERE DATE(co.created_at)>=? AND DATE(co.created_at)<=?
         GROUP BY c.id
         ORDER BY order_count DESC
         LIMIT 3",
        $last_monday, $last_sunday
    );
    
    // 4. 安全概况
    $login_fail = pdo_query(
        "SELECT COUNT(*) as cnt FROM loginlog 
         WHERE password='login fail' AND DATE(time)>=? AND DATE(time)<=?",
        $last_monday, $last_sunday
    )[0]['cnt'];
    
    // 5. 组装飞书消息
    $content = "📊 OJ平台运营周报（{$last_monday} - {$last_sunday}）\n\n";
    
    // 用户活跃
    $content .= "👤 用户活跃\n";
    $content .= "• 本周登录：{$login_users}人\n";
    $content .= "• 本周提交题目：{$submit['users']}人（{$submit['total']}次，通过率{$pass_rate}%）\n";
    $content .= "• 新增注册：{$new_users}人\n\n";
    
    // 游戏热度
    $content .= "🎮 游戏热度（本周访问次数）\n";
    if ($game_stats['available']) {
        $content .= "• AI猜画：{$game_stats['ai_drawing']}次\n";
        $content .= "• 编程启蒙：{$game_stats['coding']}次\n";
        $content .= "• 汉字打字：{$game_stats['keyboard']}次\n";
        $content .= "• 数学闯关：{$game_stats['math']}次\n";
        $content .= "• 卡片配对：{$game_stats['memory']}次\n";
    } else {
        $content .= "• 日志未配置，无法统计\n";
    }
    $content .= "\n";
    
    // 课件运营
    $content .= "📚 课件运营\n";
    $content .= "• 本周订单：{$orders['cnt']}单（¥{$orders['amount']}）\n";
    
    // 课件浏览TOP3（从日志）
    if ($game_stats['available'] && !empty($game_stats['course_views'])) {
        arsort($game_stats['course_views']);
        $top_views = array_slice($game_stats['course_views'], 0, 3, true);
        $content .= "• 课件浏览TOP3：\n";
        $idx = 1;
        foreach ($top_views as $course_id => $view_count) {
            $course_title = pdo_query("SELECT title FROM course WHERE id=?", $course_id)[0]['title'] ?? "课件#{$course_id}";
            $content .= "  {$idx}. {$course_title}（{$view_count}次）\n";
            $idx++;
        }
    }
    
    // 热销课件TOP3
    if (!empty($top_courses)) {
        $content .= "• 热销课件TOP3：\n";
        foreach ($top_courses as $i => $course) {
            $content .= "  " . ($i+1) . ". {$course['title']}（{$course['order_count']}单）\n";
        }
    }
    
    $content .= "\n⚠️ 安全概况\n";
    $content .= "• 登录失败：{$login_fail}次\n";
    
    // 推送飞书
    feishu_notify('📊 运营周报', $content, 'info');
}

/**
 * 解析Nginx访问日志
 * @param string $log_path 日志路径
 * @param string $week_start 周开始日期
 * @param string $week_end 周结束日期
 * @return array 统计结果
 */
function parse_nginx_log($log_path, $week_start, $week_end) {
    $result = [
        'available' => false,
        'ai_drawing' => 0,
        'coding' => 0,
        'keyboard' => 0,
        'math' => 0,
        'memory' => 0,
        'course_views' => []
    ];
    
    if (!file_exists($log_path)) {
        return $result;
    }
    
    $start_ts = strtotime($week_start);
    $end_ts = strtotime($week_end) + 86400;
    
    $handle = fopen($log_path, 'r');
    if (!$handle) return $result;
    
    while (($line = fgets($handle)) !== false) {
        // 解析Nginx日志时间: [10/May/2026:08:30:00 +0800]
        if (!preg_match('/\[(\d{2})\/(\w{3})\/(\d{4}):(\d{2}):(\d{2}):(\d{2})/', $line, $m)) {
            continue;
        }
        
        $log_time = strtotime("{$m[3]}-{$m[2]}-{$m[1]} {$m[4]}:{$m[5]}:{$m[6]}");
        if ($log_time < $start_ts || $log_time >= $end_ts) {
            continue;
        }
        
        // 统计游戏访问
        if (strpos($line, 'ai_drawing_game.php') !== false) {
            $result['ai_drawing']++;
        } elseif (strpos($line, 'coding_game.php') !== false) {
            $result['coding']++;
        } elseif (strpos($line, 'keyboard_game.php') !== false) {
            $result['keyboard']++;
        } elseif (strpos($line, 'math_game.php') !== false) {
            $result['math']++;
        } elseif (strpos($line, 'memory_game.php') !== false) {
            $result['memory']++;
        }
        
        // 统计课件浏览
        if (preg_match('/course_info\.php\?id=(\d+)/', $line, $cm)) {
            $cid = $cm[1];
            if (!isset($result['course_views'][$cid])) {
                $result['course_views'][$cid] = 0;
            }
            $result['course_views'][$cid]++;
        }
    }
    
    fclose($handle);
    $result['available'] = true;
    return $result;
}

// 执行推送
send_weekly_report();
```

### 5.4 Nginx日志配置

如需统计游戏和课件浏览数据，需确保Nginx访问日志已开启：

```nginx
# /etc/nginx/sites-enabled/default
server {
    # ... 其他配置
    
    access_log /var/log/nginx/access.log;
    error_log /var/log/nginx/error.log;
}
```

修改后重启Nginx：
```bash
/etc/init.d/nginx restart
```

## 七、异常处理

| 场景 | 处理方式 |
|------|----------|
| Nginx日志不存在 | 游戏和课件浏览显示"日志未配置"，其他数据正常展示 |
| 数据库连接失败 | 记录错误日志，不发送飞书消息 |
| 飞书推送失败 | 记录错误日志，可手动重试 |
| 上周无数据 | 显示为0，不报错 |
