📖 激活帮助

一、什么是授权码？

授权码是用于激活离线游戏的凭证，由您在 OJ 网站积分兑换时按填写的学校名称和机房名称生成。

💡 特点：
  • 每个授权码绑定特定的学校和机房
  • 有效期为1年
  • 激活后无需联网即可使用
  • 采用RSA数字签名保护，防篡改

二、如何获取授权码？

1

登录 OJ 网站

登录 OJ 网站（aioj.top），进入「更多」页面

2

积分兑换

找到「离线游戏」，点击积分兑换（消耗50积分），填写您的学校名称和机房名称

示例： 学校名称：XX市第一中学 机房名称：计算机教室3楼
3

获取授权码

兑换成功后页面显示JSON格式授权码，点击复制；同时通过网盘链接下载离线游戏包

三、授权码格式说明

授权码是一个JSON格式的文本，包含以下字段：

{ "school": "学校名称", "room": "机房名称", "expire": "2027-09-07", "created": "2026-09-07 10:50:00", "version": "1.0", "signature": "xxxxxxxxxxxxxxxxxxxxxx..." }
  • school：学校名称
  • room：机房名称
  • expire：有效期（YYYY-MM-DD格式）
  • created：创建时间
  • version：版本号
  • signature：RSA数字签名（用于验证授权真实性）

四、激活步骤详解

1

打开激活页面

双击打开 games/activate.html 文件

或在浏览器地址栏输入：

file:///C:/Users/您的用户名/Desktop/hustoj-games/games/activate.html
2

粘贴授权码

将网站兑换获得的授权码完整复制，粘贴到文本框中

⚠️ 注意：
  • 确保复制完整，不要遗漏任何字符
  • 不要包含多余的空格或换行
  • 检查是否包含所有必要字段
3

确认授权信息

输入授权码后，系统会自动显示：

  • ✅ 学校名称
  • ✅ 机房名称

请确认信息无误后再进行激活。

4

点击激活按钮

点击「验证授权码」按钮

5

下载授权文件

验证通过后，页面出现「⬇️ 下载 license.js」按钮，点击下载授权文件

将下载的 license.js 放入离线包 js 目录（与 auth.js 同级）；教师机本机已同步激活，可直接打开 index.html 使用

6

完成激活

激活成功后：

  • 激活页显示「✅ 授权验证通过」及操作指引
  • 打开 index.html 进入游戏主页
  • 游戏主页底部显示授权信息

五、常见错误及解决方法

❌ 错误：授权码格式错误

原因：授权码不完整或格式不正确

解决：重新复制完整的授权码，确保无多余空格

❌ 错误：授权文件签名无效，授权码可能被篡改

原因：授权内容被修改或损坏

解决：不要修改授权内容，重新在激活页粘贴验证

❌ 错误：授权已过期，请联系管理员续费

原因：授权码有效期已过（1年）

解决：登录 OJ 网站重新积分兑换

❌ 错误：未找到授权文件，请先激活

原因：离线包 js 目录缺少授权文件 license.js，或浏览器中无有效授权

解决：分发学生机请在教师机 games/activate.html 验证授权码后下载 license.js 放入离线包 js 目录（与 auth.js 同级）；单机使用可直接打开 games/activate.html 重新粘贴授权码验证

六、离线使用说明

✅ 支持完全离线使用

激活后，游戏可以完全离线运行，无需连接互联网。

适合网络受限的机房环境。

离线使用步骤：

  1. 在任意有网络的电脑上登录 OJ 网站，完成积分兑换并获取授权码
  2. 在教师机打开 games/activate.html，粘贴授权码完成验证（验证过程离线即可完成）
  3. 点击「下载 license.js」，将文件放入离线包 js 目录（与 auth.js 同级）
  4. 将整个离线包拷贝到学生机，双击 index.html 直接使用（无需再操作）

七、多机房管理

不同机房需要不同的授权码

机房1：计算机教室1楼 → 授权码1 机房2：计算机教室2楼 → 授权码2 机房3：计算机教室3楼 → 授权码3

建议：

  • 建立机房授权码清单
  • 记录每个机房的授权信息
  • 定期检查授权有效期
