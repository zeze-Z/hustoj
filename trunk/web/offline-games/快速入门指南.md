# HUSTOJ 离线游戏 - 快速入门指南

## 🚀 3分钟快速激活

### 第1步：获取授权码

1. 登录 OJ 网站（aioj.top）
2. 进入「更多」页面，找到「离线游戏」，点击积分兑换（消耗 **50 积分**）
3. 填写：**学校名称** + **机房名称**
4. 兑换成功后复制 **JSON 授权码**，并通过页面提供的**网盘链接**下载离线游戏包

---

### 第2步：激活游戏

1. 解压游戏包
2. 双击打开 `games/activate.html`
3. 粘贴授权码到文本框，点击「**验证授权码**」
4. 验证通过后点击「**⬇️ 下载 license.js**」，将下载的文件放入离线包 `js` 目录（与 `auth.js` 同级）

---

### 第3步：分发与开始游戏

1. 教师机：打开 `index.html` 即可进入游戏
2. 学生机：将整个离线包拷贝过去，双击 `index.html` 直接进入（零操作）
3. 选择想玩的游戏，享受编程乐趣！

> 💡 **提示**：向学生机房分发时，优先用上面的 license.js 方式（整包拷贝、双击即用）。仅单机换浏览器或清除浏览器数据后提示未激活时，重新打开 `games/activate.html` 粘贴同一授权码验证即可（备用方式）。

## ❓ 常见问题速查

| 问题 | 解决方法 |
|------|----------|
| 授权码格式错误 | 检查是否完整复制，无多余空格 |
| 签名无效 | 不要修改授权内容，重新在激活页粘贴验证 |
| 授权已过期 | 登录 OJ 网站重新积分兑换 |
| 换浏览器/清数据后提示未激活 | 重新打开 `games/activate.html` 粘贴授权码验证 |
| 无法打开页面 | 使用Chrome/Firefox/Edge浏览器 |
