## 概述

HUSTOJ 离线游戏是一套基于浏览器的编程教学游戏，支持在无网络环境下使用。本文档将指导您如何获取授权码并激活游戏。

### 主要特点

- ✅ **支持离线使用**：激活后无需联网即可使用
- ✅ **授权码保护**：每个授权码绑定特定学校和机房
- ✅ **有效期管理**：授权码有效期为1年
- ✅ **防篡改机制**：授权文件采用RSA数字签名保护

## 激活流程

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ 1. 网站积分兑换│───▶│ 2. 填写学校机房│───▶│ 3. 获取授权码 │───▶│ 4. 激活游戏  │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
```

### 流程说明

1. **网站积分兑换**：登录 OJ 网站（aioj.top），进入「更多」页面，找到「离线游戏」进行积分兑换（消耗 50 积分）
2. **填写学校机房**：在兑换表单中填写学校名称和机房名称
3. **获取授权码**：兑换成功后复制页面显示的 JSON 授权码，并通过网盘链接下载离线游戏包
4. **激活游戏**：在激活页面（`games/activate.html`）粘贴授权码，点击「验证授权码」，验证通过后下载 `license.js` 放入 `js` 目录

## 详细步骤

### 步骤1：网站积分兑换获取授权码

#### 兑换入口

登录 OJ 网站（aioj.top）→ 「更多」页面 → 「离线游戏」→ 积分兑换（消耗 50 积分）

#### 需要填写的信息

| 信息项 | 说明 | 示例 |
|--------|------|------|
| 学校名称 | 您所在学校的全称 | XX市第一中学 |
| 机房名称 | 使用游戏的机房名称 | 计算机教室1楼 |

#### 操作说明

1. 登录后在「更多」页面找到「离线游戏」卡片，点击「我的授权码 / 积分兑换」
2. 填写学校名称和机房名称，确认兑换（消耗 50 积分）
3. 兑换成功后页面显示 JSON 格式授权码，点击「复制授权码」并妥善保存
4. 通过页面提供的网盘下载链接获取离线游戏包

### 步骤2：下载离线游戏包

#### 下载地址

兑换成功后页面提供的网盘下载链接

#### 文件说明

| 文件名 | 大小 | 说明 |
|--------|------|------|
| hustoj-games-学校名-日期.zip | 约5MB | 离线游戏主包 |

### 步骤3：解压游戏包

1. 找到下载的 `.zip` 文件
2. 右键点击 → 选择「解压到当前文件夹」
3. 等待解压完成

#### 解压后目录结构

```
hustoj-games/
├── index.html         # 游戏主页
├── games/            # 游戏文件目录（含 activate.html 激活页面）
└── js/               # JavaScript文件（auth.js 授权校验；license.js 授权文件放这里）
```

> 说明：离线包无需预置 `license.js`。教师机验证授权码后下载该文件放入 `js` 目录，即可整包拷贝分发；本机授权同时保存在浏览器中，单机无需文件也可使用。

### 步骤4：激活授权码

#### 4.1 打开激活页面

1. 双击打开 `games/activate.html` 文件
2. 或在浏览器地址栏输入文件路径：
   ```
   file:///C:/Users/您的用户名/Desktop/hustoj-games/games/activate.html
   ```

#### 4.2 输入授权码

1. 在激活页面找到「🔑 请输入授权码」文本框
2. 将网站兑换获得的授权码完整粘贴到文本框中
3. 授权码格式示例：
   ```json
   {
     "school": "XX市第一中学",
     "room": "计算机教室3楼",
     "expire": "2027-09-07",
     "created": "2026-09-07 10:50:00",
     "version": "1.0",
     "signature": "xxxxxxxxxxxxxxxxxxxxxx..."
   }
   ```

#### 4.3 预览授权信息

输入授权码后，系统会自动显示：
- ✅ 学校名称
- ✅ 机房名称

请确认信息无误后再进行激活。

#### 4.4 点击验证按钮

1. 确认授权信息无误
2. 点击「验证授权码」按钮
3. 等待验证完成

#### 4.5 自动激活与下载授权文件

验证通过后：
1. 授权内容自动保存到浏览器（localStorage），本机自动完成激活
2. 点击页面上的「⬇️ 下载 license.js」按钮，将下载的文件放入离线包 `js` 目录（与 `auth.js` 同级），用于整包分发到学生机
3. 放好 `license.js` 后，整个离线包拷贝到学生机，双击 `index.html` 即可直接使用（学生机无需激活）

> 备用方案：仅当浏览器无法自动保存授权时，才按激活页提示将授权内容保存为 `license.dat` 文件，放到离线包根目录（与 `index.html` 同级）。

#### 4.6 完成激活

激活成功后：
- 激活页显示「✅ 授权验证通过」及分发/备用操作指引
- 打开 `index.html` 进入游戏主页
- 游戏主页底部显示授权信息（学校名 - 机房名 | 授权至 日期）

## 常见问题

### Q1：激活时提示「授权码格式错误」

**可能原因：**
- 授权码不完整，缺少部分字符
- 复制时包含了多余的空格或换行符
- 授权码不是从网站积分兑换处复制的

**解决方法：**
1. 重新复制完整的授权码
2. 确保没有多余的空格或换行
3. 检查授权码是否包含所有必要字段：school、room、expire、signature

---

### Q2：激活时提示「授权文件签名无效，授权码可能被篡改」

**可能原因：**
- 授权内容被修改过
- 使用了其他来源的授权内容
- 复制过程中内容损坏

**解决方法：**
1. 重新在激活页粘贴授权码验证
2. 不要手动修改授权内容
3. 确保从网站积分兑换处复制授权码

---

### Q3：激活时提示「授权已过期，请联系管理员续费」

**可能原因：**
- 授权码有效期已过（授权码有效期为1年）

**解决方法：**
1. 登录 OJ 网站重新积分兑换
2. 使用新的授权码重新激活

---

### Q4：激活页面无法打开

**可能原因：**
- 浏览器版本过低
- 浏览器安全设置阻止本地文件访问

**解决方法：**
1. 使用 Chrome、Firefox 或 Edge 最新版本
2. 如果使用 IE，请切换到现代浏览器
3. 尝试右键点击 `activate.html` → 选择「用...打开」

---

### Q5：激活成功后游戏主页显示「未找到授权文件，请先激活」

**可能原因：**
- 当前浏览器中无有效授权（更换了浏览器或清除了浏览器数据）
- 使用了无痕/隐私模式打开游戏页面

**解决方法：**
1. 确认离线包 `js` 目录已放入 `license.js`（整包分发场景下应已随包携带）
2. 单机使用时重新打开 `games/activate.html`，粘贴同一授权码点击「验证授权码」激活；避免使用无痕/隐私模式
3. 如浏览器始终无法自动保存授权，按激活页提示将授权内容保存为 `license.dat` 放到离线包根目录（备用方案）

---

### Q6：不同机房需要不同的授权码吗？

**答案：是的**

- 每个授权码绑定特定的学校和机房
- 不同机房需要使用不同的授权码
- 网站积分兑换时，请填写准确的机房名称

---

### Q7：授权码可以在多台电脑上使用吗？

**答案：可以**

- 同一机房的多台电脑可以使用同一个授权码
- 授权码绑定的是「学校+机房」，不是具体电脑
- 教师机验证后下载 `license.js` 放入 `js` 目录，整包拷贝到学生机即可双击直接使用，无需逐台激活

---

### Q8：如何查看当前授权状态？

**方法：**

1. 打开游戏主页（`index.html`）
2. 查看页面底部
3. 显示格式：`© 学校名 - 机房名 | 授权至 日期`

---

### Q9：游戏运行时需要联网吗？

**答案：不需要**

- 激活后完全离线运行
- 无需连接互联网
- 适合网络受限的机房环境

---

### Q10：如何更新游戏版本？

**步骤：**

1. 通过网站兑换页提供的网盘链接下载新版本游戏包
2. 保存好当前使用的授权码文本
3. 解压新版本游戏包
4. 在新版本目录打开 `games/activate.html`，粘贴同一授权码重新验证并下载 `license.js` 放入 `js` 目录
5. 重新打开游戏

## 注意事项

### ⚠️ 重要提醒

1. **不要修改授权内容**
   - 授权码采用数字签名保护
   - 任何修改都会导致授权失效
   - 如需修改学校或机房名称，请在网站重新积分兑换

2. **妥善保管授权码**
   - 授权码是激活游戏的唯一凭证
   - 建议保存在安全的地方（如文本文件）
   - 避免泄露给他人

3. **定期备份授权码**
   - 将授权码文本备份到安全位置
   - 更换浏览器或清除浏览器数据后，可重新粘贴授权码激活

4. **浏览器兼容性**
   - 推荐使用 Chrome、Firefox 或 Edge
   - 不支持 IE 浏览器
   - 确保浏览器版本为最新

5. **文件路径**
   - 游戏文件夹路径不要包含中文或特殊字符
   - 推荐使用英文路径，如：`C:\Games\hustoj-games\`

6. **多机房管理**
   - 每个机房使用独立的授权码
   - 建议建立机房授权码清单
   - 便于管理和续费
